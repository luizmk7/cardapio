# Cardápio Padrão — Brasa Espetaria

Modelo original de cardápio digital, importado de `brasa-espetaria-atualizado.zip`.

Site estático com HTML, CSS e JavaScript. Para executar localmente:

```sh
python3 -m http.server 8000
```

Abra http://localhost:8000. Publique os arquivos da raiz em uma hospedagem estática, sem etapa de build.

- `config.js`: dados da loja, contato, horários e banner.
- `menu.js`: produtos, preços e adicionais.
- `assets/`: imagens do modelo.

Consulte `LEIA-ME.txt` para as orientações originais.
